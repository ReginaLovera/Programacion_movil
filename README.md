# Juego de Piezas (`com.example.papa`)

Proyecto Android desarrollado en Java (`AppCompatActivity`) para seleccionar piezas (`Ojos`, `Nariz`, `Cabello`, `Boca` y `Pies`), arrastrarlas y soltarlas sobre un escenario (`FrameLayout`) y evaluar la precisión de su posición respecto a coordenadas objetivo en escala `0..500`.

- **Autora:** Regina Lovera Jerónimo

## Archivos incluidos en este paquete
- `app/src/main/java/com/example/papa/MainActivity.java`
- `app/src/main/res/layout/activity_main.xml`
- `app/src/main/res/values/strings.xml`
- `.gitignore`
- `README.md`

## Recursos adicionales que debes colocar en `app/src/main/`
- Imágenes en `app/src/main/res/drawable/`: `cuerpo.*`, `ojos.*`, `nariz.*`, `cabello.*`, `boca.*`, `pies.*`
- Fuente tipográfica en `app/src/main/res/font/`: `ps.ttf` (o fuente compatible referenciada como `R.font.ps`)
